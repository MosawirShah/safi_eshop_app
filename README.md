# 🛍️ Safi E-Shop

**Safi E-Shop** is an e-commerce application designed to provide users with a convenient online shopping experience. The project focuses on essential e-commerce functionality, product browsing, customer interaction, and a basic sentiment analysis feature for customer comments.

One of the interesting aspects of this project is the integration of sentiment analysis to examine customer feedback and identify the general sentiment expressed in comments.

## 🚀 Key Features

- **E-Commerce Functionality**
  - Browse available products.
  - View product information and details.
  - Explore products through an organized shopping interface.

- **Customer Feedback**
  - Collect and display customer comments.
  - Allow customers to share their opinions and experiences.

- **Sentiment Analysis**
  - Perform basic sentiment analysis on customer comments.
  - Identify positive and negative opinions.
  - Use customer feedback to understand general product perception.

- **User-Friendly Interface**
  - Simple and intuitive navigation.
  - Organized product presentation.
  - Focus on a smooth shopping experience.

## 🧠 Sentiment Analysis

A small sentiment analysis component is included in this project to explore how Natural Language Processing (NLP) can be applied to e-commerce applications.

The purpose is to analyze customer comments and classify their overall sentiment.

Possible sentiment categories:
- Positive
- Negative
- Neutral

This feature demonstrates how AI and NLP techniques can help e-commerce platforms better understand customer opinions and feedback.
